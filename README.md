# 3D-візуалізація квартири

Статична інтерактивна сторінка без зовнішніх залежностей.

## Локальний запуск

```sh
npm run dev
```

Сторінка буде доступна на `http://localhost:4173/`.

## Деплой на Vercel

Імпортуйте папку проєкту як статичний Vercel проєкт. Налаштування збірки не потрібні:

- Build Command: залишити порожнім
- Output Directory: `.`
- Framework Preset: Other
